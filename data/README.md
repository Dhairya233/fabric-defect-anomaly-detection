# data/

Everything in this folder except this file is git-ignored. The dataset is never committed.

Layout produced by the scripts:

```
data/
  archives/     the three official .7z files, placed here by you
  raw/          extracted images and masks (written by scripts/download_data.py)
  manifest.csv  one row per usable image (written by scripts/prepare_data.py)
```

Source: AITEX Fabric Image Database (AFID), https://www.aitex.es/afid/
Citation requested by the authors: Silvestre-Blanes, Albero-Albero, Miralles,
Pérez-Llorens, Moreno. "AFID: a public fabric image database for defect detection."
AUTEX Research Journal, No. 4, 2019.
The dataset page states no licence, so the data is not redistributed.
